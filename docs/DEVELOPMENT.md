# Development Guide

## Локальная разработка

```bash
npm start
```

Dev server отдаёт проект как статические файлы и не выполняет сборку.

## Проверка качества

```bash
npm run check
npm test
```

Проверки включают:

- валидность локальных ES Module импортов;
- базовый поиск потенциально опасных паттернов;
- тесты стабильных бизнес-констант и конфигурации.

## Процесс внесения изменений

1. Создайте отдельную ветку.
2. Вносите изменения маленькими шагами.
3. Не меняйте бизнес-константы без явного решения.
4. Новую логику размещайте в подходящем модуле.
5. После правок запускайте проверки.
6. Перед merge выполните ручную проверку сценариев из `docs/MANUAL_QA.md`.

## Правила кода

- Использовать только HTML, CSS и Vanilla JavaScript.
- Не добавлять зависимости без веской причины.
- Не смешивать Canvas UI, input, state machine и конфигурацию в одном файле.
- Сложные условия выносить в именованные переменные или функции.
- Повторяющиеся значения переносить в `src/config`.
- В пользовательский ввод не верить по умолчанию.

## Добавление новой сущности

1. Добавьте файл в `src/entities/<category>`.
2. Подключите нужные константы из `src/config`.
3. Не обращайтесь напрямую к DOM из игровой сущности.
4. Если нужна чистая логика, вынесите её в `src/utils`.
5. Добавьте тест, если правило можно проверить без браузера.
