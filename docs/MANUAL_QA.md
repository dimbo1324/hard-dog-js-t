# Manual QA Checklist

Проверять в актуальных версиях Chrome, Edge или Firefox.

## Запуск

1. Выполнить `npm start`.
2. Открыть `http://localhost:4173`.
3. Убедиться, что Canvas появился по центру экрана.
4. Убедиться, что фон, игрок, жизни, счёт и таймер отображаются.

## Управление

- `ArrowRight` / `D` / `В` двигают игрока вправо.
- `ArrowLeft` / `A` / `Ф` двигают игрока влево.
- `ArrowUp` / `W` / `Ц` запускают прыжок.
- `ArrowDown` / `S` / `Ы` переводят игрока в sitting-state.
- `Enter` / `Space` запускают rolling/diving поведение.
- Удержание `U` 3 секунды переключает debug-режим.

## Игровые сценарии

- Через 18 секунд игра должна завершиться.
- При столкновении без rolling/diving должна уменьшаться жизнь.
- При rolling/diving и столкновении с врагом должен увеличиваться счёт.
- При нуле жизней игра должна завершиться.
- При завершении игры animation loop должен остановиться.

## Адаптивность

- Canvas должен помещаться в viewport.
- При узком экране не должно появляться горизонтальной прокрутки страницы.

## Ошибки

- При удалении/переименовании критичного изображения ошибка загрузки должна быть видна в консоли.
- При отсутствии Canvas должен появиться fallback error message в DOM.
