# Known Limitations and Technical Debt

## Сохранено намеренно

- Restart prompt отображается в UI, но restart-механика не добавлена. Это было в исходной версии; поведение сохранено, чтобы не менять бизнес-логику.
- Игра полностью завязана на Canvas, поэтому большинство visual/e2e проверок нужно выполнять в браузере.
- Размеры спрайтов и кадры анимаций зависят от текущих изображений.

## Следующие безопасные улучшения

1. Добавить restart-механику отдельной задачей и зафиксировать новое поведение тестом.
2. Добавить Playwright-тесты для браузерной smoke-проверки.
3. Добавить pre-commit hooks только после согласования инструментария.
4. Добавить аудио-модуль, если будет принято решение использовать звуки.
5. Вынести game balance в отдельный JSON/config layer, если игра будет масштабироваться.
6. Добавить accessibility-инструкцию рядом с Canvas для пользователей клавиатуры.
